## Dashboard specification

Build the interactive view from `duka_sales.csv`, using the same definitions as the board report:

- **Scorecards:** H1 revenue (KES), order count, and average order value (KES).
- **Monthly trend:** revenue by month, January–June 2026.
- **Breakdowns:** revenue by branch and revenue by product category.
- **Controls:** date-range selector and a drop-down filter for branch.
- **Optional comparison:** average order value by channel.

Use the same restrained palette and chart titles as the report. Set the date range to January 1–June 30, 2026, and verify that changing either control updates all applicable visuals.
